# UNC720-CJG
Conversion dataset for in-vitro in-vivo extrapolation

Required files:
HTTK_conversions.ipynb - most of the work is annoted here
HTTK_conversions.Rmd

Two datasets must be unzipped in the same folder as the notebooks:
activities_with_dsstoxids.csv - needed to generate the graphs at the end of the python notebook
activities_with_inchikeys_to_filter_in_R_all.csv - needed to demonstrate the ctxR library in the R notebook
